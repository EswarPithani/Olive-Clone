# Olive Clone – Frontend Assessment

## Overview

This project is a frontend implementation of a landing page based on a provided screenshot reference. The goal is to accurately translate a visual design into a functional and structured React application.

## Tech Stack

* React (Create React App)
* CSS (modular component-based styling)

## Features

* Structured component architecture (Navbar, Hero, Product Demo, Trust Badge)
* Pixel-approximate UI matching the reference
* Responsive layout
* Animated product demo slider

## Installation & Setup

```
npm install
npm start
```

Runs the app in development mode at:

```
http://localhost:3000
```

## Build

```
npm run build
```

## Notes

* This project focuses only on frontend implementation.
* No backend or API integration is included.
* Assets are locally managed.
* Styling is implemented using plain CSS for clarity and control.

## Deployment

Deployed using Vercel.

## Objective

Demonstrate ability to:

* Convert UI design into code
* Maintain clean component structure
* Apply consistent styling and layout techniques
* Implement basic UI animations
